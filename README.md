# Dr Abby Clinic — website revamp (mock)

Static build of the proposed new abclinic.com.my: the clinic's own content, reorganised into the revamp plan (72 pages, 4 offers, 58 articles). Generated by a build script from a content data file; edit the source, not these files.

- All links are relative, so the site runs at a domain root or in a sub-folder (GitHub Pages).
- `_redirects` lists the 301s for hosts that read it; every old URL also has a redirect page.
- Booking and contact forms open WhatsApp; tracking is switched off in this mock.
